# 月份与会议时间合并更新

管理员菜单合并为“月份与会议时间”。当前月份设置、日期多选日历、批量时间段和已有日期放在同一页；创建其他月份和月份列表折叠展示。旧 #/slots 路由兼容跳转到合并页。

批量添加支持任意多天、整月全选、工作日全选、多个共同时间段、统一人数上限；服务端原子写入，重复时间跳过，跨月份/无效时间/过期版本拒绝。升级不更改已有会议时间或填写记录。

验证：真实 PostgreSQL 事务验证 3 天 × 2 段一次添加、容量 0、重复跳过、跨月整批拒绝、时间校验、版本冲突；8 项算法测试通过。Chrome 界面验证闰年二月、整月与工作日多选、多段批量请求、原有编辑、事件无重复和手机宽度。

# 当前版本：统一月份填写入口

已移除逐人可选时间权限和个人链接操作。所有班主任使用同一入口，选择年月和姓名，查看相同会议时间和已生成的安排。草稿隐藏时间，无配置月份显示空状态。首次提交时间保留，重新提交替换选择；月份关闭、跨月份时间、版本冲突仍由数据库拒绝。

数据库升级：`supabase/updates/shared-portal.sql`，加上 `functions.sql` 中管理员命令的更新。既有可用时间记录通过迁移保留。新版 Edge Function 使用公共月份/姓名流程；旧 token RPC 撤销访问。

验证：8 项算法测试（含 300 组旧版对照）通过；真实 PostgreSQL shared-portal.sql 事务测试通过（草稿、空月份、无个人权限也能读取/提交、姓名切换、跨月份拒绝、空提交、版本冲突、关闭写入、公开会议安排、匿名数据库访问拒绝）。真实 Chrome 手机尺寸验证月份/姓名切换、云端提交和重新读取，零浏览器异常。测试数据清理。

旧版历史测试 security.sql / isolation.sql 针对已退役的个人链接模式；新版使用 shared-portal.sql。
