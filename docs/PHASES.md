# 管理员修改与删除填写

填写情况新增修改/删除填写按钮。修改弹窗按日期显示时间段，可取消某段或整天选择，再保存替换。空选择保存仍为已填写；删除整份填写恢复未填写。仅作用于选定月份/老师；删除不再可用的固定安排，旧排期标记过期。原始填写来源保留，首次提交时间在修改时保留；删除重置提交时间。月份和提交版本均验证，防止覆盖并发更改。

数据库迁移 admin-submissions.sql 已应用。真实 PostgreSQL 事务验证修改、空选择、删除、首次时间保留、跨月份拒绝、并发冲突、其他老师不受影响、非管理员拒绝。Chrome 验证已有勾选回显、改日期/时间、弹窗冲突提示、确认删除。

# 日历与负责人日期选择更新

日历直接显示每段时间和班主任姓名，姓名自动换行，全部会议直接显示，仍可点击查看详情。负责人可参加时间改成多列日期选择，包含日期全选/清空选择；保存日期时展开为当天所有已配置时间段。历史部分时段可用的日期显示为选中，保存后统一按整天处理。

Chrome 验证姓名显示、详情弹窗、日期去重、多列布局、全选/清空、日期展开为时间段保存、负责人切换均通过。未自动修改已有数据库记录。

验证：空月份页面显示日期和时间、日本时区默认值、单套表单、创建后批量保存调用顺序；原有日期多选/闰年/工作日/编辑测试和算法测试通过。
